Każdy skrót przełącznika zwykle korzysta z ustawień globalnych. `shortcutOverrides`
pozwala użyć innych ustawień dla skrótu: kompaktowej listy alfabetycznej dla jednego
skrótu klawiszowego i pełnowymiarowych podglądów okien dla innego, w tej samej
instalacji.

Mechanizm współpracuje z `scopedShortcutList`, który tworzy dodatkowe skróty globalne
otwierające przełącznik przefiltrowany do podzbioru okien. Razem pozwalają użyć jednego
skrótu do „wszystkich moich okien jako podglądów”, a drugiego do „tylko okien tej
aplikacji jako listy”.

## Cele

Nadpisanie wskazuje skrót, którego dotyczy, w polu `target`:

| `target` | Skrót |
| --- | --- |
| `switchApps` | Główny przełącznik (domyślnie <kbd>⌘Tab</kbd>) |
| `switchWindows` | Przełącznik okien (domyślnie <kbd>⌘`</kbd>) |
| `scoped.<id>` | Skrót o ograniczonym zakresie, gdzie `<id>` jest jego `id` w `scopedShortcutList` |

```json title="config.json"
{
  "shortcutOverrides": [
    {
      "target": "switchWindows",
      "layoutMode": "windowPreview",
      "panelScalePercent": "140",
      "sortOrder": "mruWindows"
    },
    {
      "target": "scoped.0",
      "layoutMode": "list",
      "listWidthPercent": "60",
      "showMinimized": "false"
    }
  ]
}
```

<Callout type="warn" title="Wartości nadpisań są ciągami znaków">
Nadpisania są przechowywane jako słowniki ciągów znaków, dlatego **każda** wartość jest
zapisana jako ciąg JSON — `"140"`, a nie `140`; `"false"`, a nie `false`. Odpowiadające
im klucze globalne używają swoich naturalnych typów. Generowany plik `schema.json`
wymusza tę zasadę, więc edytor oznaczy błąd.
</Callout>

Każde pominięte pole dziedziczy ustawienie globalne. Nadpisanie zawierające tylko
`target` jest równoważne brakowi nadpisania i zostaje usunięte przy następnym zapisie
pliku.

## Pola

Nazwy pól przeważnie odpowiadają nazwom kluczy globalnych — ich działanie opisuje
[dokumentacja konfiguracji](/config-reference). Trzy nazwy są skrócone:
`showMinimized`, `showHidden` i `showWindowless` odpowiadają
`showMinimizedWindows`, `showHiddenApps` i `showWindowlessApps`.

`spaceScope` przyjmuje tutaj dodatkową wartość `"inherit"`, która stosuje ustawienie
globalne.

<ConfigObject name="shortcutOverrides" />

Nieznane pola są zachowywane bez zmian, a nie usuwane, dlatego otwarcie konfiguracji w
starszej wersji aplikacji nie usunie nadpisań, których ta wersja jeszcze nie rozumie.

## Skróty o ograniczonym zakresie

`scopedShortcutList` definiuje dodatkowe globalne skróty klawiszowe, z których każdy
otwiera już przefiltrowany przełącznik. Dodawaj i usuwaj je w **Ustawienia → Profile**.

```json title="config.json"
{
  "scopedShortcutList": [
    { "id": "0", "scope": "currentAppWindows", "name": "scopedSwitch1" },
    { "id": "1", "scope": "minimizedOnly", "name": "scopedSwitch2" }
  ]
}
```

<ConfigObject name="scopedShortcutList" />

<Callout type="info" title="Kombinacji klawiszy nie ma w tym pliku">
`name` jest etykietą, *pod którą* zarejestrowano kombinację; sama kombinacja znajduje
się poza przestrzenią nazw `Switcher.*` i nie jest synchronizowana. Skopiowanie
konfiguracji na innego Maca przenosi skróty o ograniczonym zakresie i ich ustawienia —
kombinacje klawiszy rejestruje się tam ponownie w Ustawienia → Profile.
</Callout>

Identyfikatory są przydzielane rosnąco i nigdy nie są używane ponownie, dzięki czemu wpis
zachowuje zarejestrowaną kombinację oraz wpis `shortcutOverrides` podczas dodawania,
usuwania i zmiany kolejności. `id` jest dziesiętnym **ciągiem znaków**, zgodnie ze
sposobem przechowywania listy.

<Callout type="warn">
Nie wybieraj ręcznie identyfikatorów kolidujących z istniejącym wpisem i nie zmieniaj
`nextScopedShortcutID` — jest to licznik alokatora. Dodawanie wpisów w oknie ustawień
pozwala uniknąć obu problemów.
</Callout>

## Bezpośrednie skróty aplikacji

Niezależnie od skrótów o ograniczonym zakresie, choć często używane razem z nimi:
`directActivationBindings` przypisuje identyfikator pakietu do każdego z dziewięciu
miejsc skrótu „uaktywnij lub uruchom tę aplikację”. Lista zawsze zawiera dokładnie
dziewięć wpisów; pusty ciąg pozostawia miejsce nieużywane.

```json title="config.json"
{
  "directActivationBindings": [
    "com.apple.Safari",
    "com.googlecode.iterm2",
    "",
    "",
    "",
    "",
    "",
    "",
    ""
  ]
}
```

Kombinacje klawiszy dla tych miejsc również są rejestrowane poza tym plikiem.

## Pełny przykład

Konfiguracja z trzema odrębnymi przełącznikami:

```json title="config.json"
{
  "layoutMode": "iconDock",
  "sortOrder": "mru",
  "spaceScope": "allSpaces",

  "scopedShortcutList": [
    { "id": "0", "scope": "currentAppWindows", "name": "scopedSwitch1" }
  ],

  "shortcutOverrides": [
    {
      "target": "switchWindows",
      "layoutMode": "windowPreview",
      "sortOrder": "mruWindows",
      "panelScalePercent": "130"
    },
    {
      "target": "scoped.0",
      "layoutMode": "list",
      "listWidthPercent": "50",
      "showWindowTitleLabel": "true",
      "spaceScope": "inherit"
    }
  ]
}
```

- <kbd>⌘Tab</kbd> — siatka ikon aplikacji, od ostatnio używanej, ze wszystkich biurek.
- <kbd>⌘`</kbd> — duże podglądy okien aktywnej aplikacji, uporządkowane według ostatniego użycia okna.
- **Skrót o ograniczonym zakresie** — wąska lista okien bieżącej aplikacji z pełnymi tytułami.
